# Mirage v1.0 M1 实施计划（Android 解码显示与 adb reverse 全链路）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 M1：Android 端 TCP 收流、MediaCodec 硬解、SurfaceView 等比渲染，通过 `adb reverse` 与真实 Mac Helper 跑通镜像显示全链路。

**Architecture:** Android 端 TCP 收流 → 自定义帧解析 → MediaCodec 硬解 → SurfaceView 等比显示；HELLO 上报设备尺寸/方向，SESSION_CONFIG 驱动解码器重建，断线后显示原因并按现有流程重连。M0 的 Mac Helper 与 `mock_mac.py` 是服务端。

**Tech Stack:** Kotlin 2.2 / Jetpack Compose / MediaCodec / SurfaceView / Gradle；adb reverse；Python 3（`mock_mac.py`）。

**Spec:** `docs/superpowers/specs/2026-11-13-mirage-design.md`

**前置:** 先完成 [M0 实施计划](2026-11-13-mirage-m0.md)，确保 `protocol/vectors.json`、Mac Helper 与 `tools/mock_mac.py` 可用。

## Global Constraints

- Android：minSdk 26，compileSdk 36，targetSdk 36；构建 JDK 17。
- 帧协议：`[u32 length][u8 type][payload]`，大端，`length = 1 + payload`，单帧上限 8 MiB。
- 默认端口 7777；M1 走 `adb reverse`，**不实现 TLS**（TLS 属 M4）。
- v1.0 不做输入；INPUT（type 4）只定义不实现。
- 画面按视频宽高比居中适配，不拉伸；黑边不参与渲染。
- 过程文档（`docs/` 下设计与计划）暂不提交；代码按任务提交。
- 每个任务结束必须真机/模拟器跑通该任务的验证命令，不通过不进入下一任务。

## 环境前置

- 已核实：Android SDK platforms 33–37、build-tools 36/37、JDK 17（`/Library/Java/JavaVirtualMachines/corretto-17.0.18`）、Gradle wrapper 8.13 已缓存。
- **Android 首次 Gradle 同步需要外网**下载 Kotlin/Compose 依赖；离线环境需先准备依赖缓存。
- 设备：Android 平板（性能基准）与手机各一台，开启 USB 调试。
- Mac 侧 M0 已完成；`tools/mock_mac.py` 与 `/tmp/mirage_test.h264` 可用。

## Review Focus

1. **解码器初始化失败**：`csd-0/csd-1` 配置失败时必须回退 in-band 参数集；没有可用 H.264 解码器时明确报错，不黑屏无提示（Task 3 验证）。
2. **Surface 生命周期**：Surface 销毁/重建时不能把已释放的 Surface 交给解码器；旋转/切换配置后重建解码器（Task 3/4 验证）。
3. **首帧关键帧**：连接后先请求关键帧；关键帧之前的非关键帧不能导致花屏或崩溃（Task 3/4 验证）。
4. **断线/心跳**：超过 3 秒无任何帧显示「连接无响应」；断开后回连接页并显示原因，不崩溃（Task 4 验证）。
5. **画面比例**：手机与 Mac 分辨率比例不同时居中留黑边，不拉伸、不错位（Task 3 验证）。
6. **adb reverse 缺失**：未执行 `adb reverse` 时连接失败要给出可操作提示，不误报为 Mac 崩溃（Task 5 验证）。

## Task 2：Kotlin 协议解析与共享向量测试

**Files:**
- Create: `android/app/src/main/java/app/mirage/net/Protocol.kt`
- Test: `android/app/src/test/java/app/mirage/net/ProtocolTest.kt`

**Interfaces:**
- Produces（与 Swift 同名语义）：
  - `enum class MessageType(val id: Int) { HELLO(1), SESSION_CONFIG(2), VIDEO(3), INPUT(4), FEEDBACK(5), CTRL(6), PING(7), BYE(8) }`
  - `class FrameDecoder { fun append(data: ByteArray); fun next(): Frame? }`（`Frame` 含 `type: Int`, `payload: ByteArray`；超过 8 MiB 抛 `ProtocolException`）
  - `object Messages`：`encodeHello(Hello): ByteArray`、`decodeHello(ByteArray): Hello`、`decodeSessionConfig`、`decodeVideo(ByteArray): VideoFrame`、`encodePing/decodePing`。
  - `data class Hello(...)` 字段与 Swift 一致；`data class SessionConfig(...)`；`data class VideoFrame(val header: VideoHeader, val annexB: ByteArray)`。

- [ ] **Step 1: 写失败的 JVM 单测**

读取仓库根 `protocol/vectors.json`：从 `System.getProperty("user.dir")` 逐级向上查找该文件（Gradle 单测工作目录通常是 `android/app`），找不到则测试失败并提示路径。
- HELLO 解析 `hex` 后字段与 `fields` 一致；`encodeHello` 结果等于 `hex`。
- VIDEO 前缀与字段一致；VIDEO 往返一致。
- 分片、连续多帧、超大长度（抛异常）、截断（返回 null）。

**Interfaces:**
- Produces：
  - `class VideoDecoder(surface: Surface, config: SessionConfig, onError: (String) -> Unit)`；`fun submit(frame: VideoFrame)`；`fun release()`。
  - 解码配置：H.264，异步模式；`KEY_LOW_LATENCY=1`（API 30+）、`KEY_PRIORITY=0`（API 28+）、`KEY_OPERATING_RATE=config.fps`（逐项 try/catch）。
  - 参数集：把关键帧 Annex-B 中 SPS/PPS 提取为 `csd-0`/`csd-1`（无则先送 `BUFFER_FLAG_CODEC_CONFIG`）。
  - 输出：`releaseOutputBuffer(index, true)` 立即渲染；积压时丢弃旧帧。

- Modify: `android/app/src/main/java/app/mirage/ui/ConnectScreen.kt`

**Interfaces:**
- Produces：
  - `class MirageClient(host: String, port: Int, listener: Listener)`；`interface Listener { fun onConfig(config: SessionConfig); fun onVideo(frame: VideoFrame); fun onClosed(reason: String) }`；`fun connect()`（后台线程）；`fun close()`。
  - 连接后立即发送 HELLO（screen 尺寸取设备真实像素与 dpi，deviceID 首次生成并存入 `SharedPreferences`）。
  - 收包循环用 `FrameDecoder`；VIDEO 交给 `VideoDecoder`；SESSION_CONFIG 重建解码器；断开时回调 `onClosed`。
  - 心跳：收到 PING 立即回 PONG；超过 3 秒无任何帧显示「连接无响应」。

- [ ] **Step 1: 实现客户端与 HELLO**

HELLO 字段：`screenWidth/Height` 用 `resources.displayMetrics.widthPixels/heightPixels`（或 `Display.getRealMetrics`），`xdpi/ydpi` 取整，`maxFPS` 取 `Display.refreshRate` 取整，`codecs=1`，`features=0`，`rotation` 按当前方向，`name` 用设备型号。

- [ ] **Step 2: 接入 UI 与解码器**

连接成功后切到 SurfaceView 全屏；断开回连接页并显示原因。
